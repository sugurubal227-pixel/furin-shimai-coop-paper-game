# 風鈴仕舞いの合図

二人で記録を伝え合い、三つの風鈴を棚に戻す、日本語の協力パズルです。進行役は要りません。遊びに必要な本編と、任意のヒント・解答を無料で配布する完結版です。

## 用意するもの

- 遊ぶ成人二人
- A4・白黒・片面で印刷した「遊ぶ紙」3ページ
- ペン

切り貼り、音を鳴らす道具、外部検索、遊ぶためのアプリ登録は不要です。PDFをダウンロードしてから遊べます。

## ダウンロードと始め方

1. [遊ぶ紙をダウンロード（PDF・3ページ）](https://github.com/sugurubal227-pixel/furin-shimai-coop-paper-game/releases/download/v0.1.0/playable.pdf)
2. 1ページ目の共通案内を二人で読みます。
3. 2ページ目のA役と、3ページ目のB役を一人一枚ずつ持ちます。役割紙を直接見せず、情報を言葉で伝え合ってください。
4. 左・中央・右に戻す風鈴の札と音を、二人の記録から決めます。詳しいルールと記入欄は紙にあります。

### 困ったとき・答えを確かめるときだけ

[ヒントと解答を開く（別PDF・1ページ）](https://github.com/sugurubal227-pixel/furin-shimai-coop-paper-game/releases/download/v0.1.0/hints-and-solution.pdf)

**この別紙には答えが載っています。自力で続けたい場合は、必要になるまで開かないでください。** 本編を買い足す必要はありません。
