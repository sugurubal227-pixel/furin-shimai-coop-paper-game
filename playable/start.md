# 風鈴仕舞いの合図

二人で遊ぶ小さな紙の謎

共通の案内 / 最初に二人で読む

## 夜の工房に、三つだけ

祭りのあとの風鈴工房。最後の三つを棚に戻せば、今日の仕事は終わりです。ところが、札を外した場所と音の記録が、二人の日誌に分かれてしまいました。

あなたたちは工房の片付け係です。記録を声で伝え合い、左・中央・右に戻す風鈴を決めてください。実物の音を聞く必要はありません。

## 分ける前に確認

次の紙を一枚ずつ持ちます。Aは「形の記録」、Bは「音の記録」。互いの役割紙を直接見せず、書かれている情報は自由に声で伝えて構いません。

使うのはこの三枚とペンだけです。紙を切る、音を出す、検索する、登録する、進行役を決める必要はありません。

## 全員が知っている約束

場所は左・中央・右の三か所。札の形は「丸・三角・四角」、音の名前は「高・中・低」です。それぞれを一度ずつ使い、各場所に形と音を一つずつ組み合わせます。

形と音の組み合わせは最初は不明です。現実の形や材質から音を推測しないでください。二人の記録はすべて正しく、この紙にない特別な規則はありません。

## 三か所が決まったら

左・中央・右の「札の形と音」を二人で書き、双方の記録と矛盾しないか確かめます。すべての条件に合う配置が一つに決まれば片付けは完了です。

困った場合だけ別紙のヒントを使えます。解答も別紙にあります。必要になるまでは閉じておいてください。
